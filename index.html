The Three Cups

A puzzle that looks easy until it's your turn.

The trick

Every move flips exactly two cups. The goal: turn all three cups mouth down.

The secret (spoilers)

Count the cups that are mouth up.

My start
2 up, even
Your start
1 up, odd
Goal
0 up, even

A move flips two cups, so there are only three kinds of move:

  • → −2 up
  • → +2 up
  • → ±0 up

The number of mouth-up cups can rise and fall, but it can never switch between odd and even. A property that no move can change is called an invariant. My cups started with an even count, the same as the goal. Yours started odd, so no sequence of moves, however long, reaches zero.

The sneaky part. When I set the cups up for you, I flipped only the middle one. A single flip is the one move the rules forbid, and it's exactly what turns even into odd. Doing this trick in person, turn the middle cup over casually while you "put them back the way they were."

In binary. Write mouth down as 0 and mouth up as 1. A move XORs two cups with 1, which XORs the XOR of all the cups with 1 ⊕ 1 = 0, leaving it unchanged. Mine: 1 ⊕ 0 ⊕ 1 = 0. Yours: 0 ⊕ 1 ⊕ 0 = 1. The goal: 0 ⊕ 0 ⊕ 0 = 0.

It works the other way too. With any number of cups, if an even number are mouth up you can always finish: pair them off and flip each pair. So parity is the whole story. Try it below.
